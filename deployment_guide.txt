PANDUAN DEPLOYMENT GENTIX APPS (SUB-DIRECTORY)
==============================================
URL Target: sekelik-news.com/gentix-apps

1. STRUKTUR FOLDER DI HOSTING
-----------------------------
Agar aman, JANGAN letakkan seluruh folder Laravel di dalam public_html.
Gunakan struktur ini:

/home/username/
├── gentix-apps/          <-- (Letakkan SEMUA file project Anda di sini, kecuali folder public)
│   ├── app/
│   ├── bootstrap/
│   ├── config/
│   └── ...
└── public_html/
    ├── index.php         <-- (Ini milik sekelik-news.com)
    └── gentix-apps/      <-- (Buat folder baru, pindahkan isi folder 'public' Laravel ke sini)
        ├── css/
        ├── js/
        ├── index.php
        └── .htaccess

2. MODIFIKASI index.php (PENTING)
--------------------------------
Buka file `public_html/gentix-apps/index.php`, cari dan ubah baris berikut agar mengarah ke folder inti:

Baris 34:
$app = require_once __DIR__.'/../../gentix-apps/bootstrap/app.php';

Baris 47:
require __DIR__.'/../../gentix-apps/vendor/autoload.php';

*(Catatan: Jumlah '../' tergantung kedalaman folder Anda)*

3. KONFIGURASI .env
-------------------
Sesuaikan file `.env` di dalam folder `/home/username/gentix-apps/.env`:

APP_URL=https://sekelik-news.com/gentix-apps
ASSET_URL=https://sekelik-news.com/gentix-apps
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_DATABASE=nama_db_anda
DB_USERNAME=user_db_anda
DB_PASSWORD=pass_db_anda

4. KONFIGURASI .htaccess (SUB-DIRECTORY)
----------------------------------------
Buka `public_html/gentix-apps/.htaccess`, pastikan ada baris ini agar routing Laravel tidak bentrok dengan website utama:

<IfModule mod_rewrite.c>
    RewriteEngine On
    RewriteBase /gentix-apps/
    RewriteCond %{REQUEST_FILENAME} !-d
    RewriteCond %{REQUEST_FILENAME} !-f
    RewriteRule ^ index.php [L]
</IfModule>

5. PENANGANAN STORAGE (FOTO REDEEM)
-----------------------------------
Karena folder storage Laravel berada di luar `public_html`, symlink standar `php artisan storage:link` tidak akan bekerja dengan benar.

Solusi Manual (Gunakan File Manager/SSH):
Buatlah symlink dari:
`/home/username/gentix-apps/storage/app/public` 
ke 
`/home/username/public_html/gentix-apps/storage`

Jika hosting tidak mendukung SSH, Anda bisa membuat file `link.php` di dalam `public_html/gentix-apps/` berisi:
<?php
symlink('/home/username/gentix-apps/storage/app/public', '/home/username/public_html/gentix-apps/storage');
echo "Symlink Berhasil Dibuat";
?>
Lalu akses `sekelik-news.com/gentix-apps/link.php` sekali saja.

6. OPTIMASI AKHIR
-----------------
Jalankan perintah ini via SSH (jika ada) atau gunakan Route temporer:
- php artisan config:cache
- php artisan route:cache
- php artisan view:cache
